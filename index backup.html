Integrações — iFood & Brendi

8 operações · dados de exemplo, prontos para conexão com credenciais reais
Esta tela está estruturada para consumir os endpoints abertos do iFood (Merchant/Order API, incluindo abertura/fechamento de loja) e da Brendi por operação (cidade + marca). O toggle "loja aberta/fechada" de cada card já está pronto para disparar a chamada de status em ambas as plataformas simultaneamente. Como este protótipo roda sem acesso à internet e sem suas credenciais, os pedidos e sincronizações abaixo são simulados — a ligação com as APIs reais é o próximo passo, plugando as chaves de cada uma das 8 lojas nos campos de configuração desta tela.
